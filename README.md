# طلایی شو

نسخه آغازین نمایشی و راست‌چین سامانه آزمون‌یار.

## انتشار با GitHub Pages
1. فایل‌های این پوشه را مستقیماً در ریشه مخزن بارگذاری کنید؛ فایل `index.html` باید در ریشه باشد.
2. در تنظیمات مخزن، بخش Pages را باز کنید.
3. منبع را روی Deploy from a branch، شاخه `main` و پوشه ریشه قرار دهید.

## ورود آزمایشی دبیر
رمز محلی نمونه: `2468`

## محدودیت‌های مهم
این نسخه فقط یک نمونه فرانت‌اند است. اطلاعات با localStorage در همان مرورگر ذخیره می‌شوند و بین گوشی دبیر و دانش‌آموز همگام‌سازی نمی‌شوند. رمز دبیر برای نمایش آزمایشی است و احراز هویت امن محسوب نمی‌شود. اتصال پایگاه داده، همگام‌سازی آنلاین، تصحیح تشریحی، گزارش PDF، رتبه‌بندی و کنترل تقلب هنوز پیاده‌سازی نشده‌اند. فایل schema.sql صرفاً طرح اولیه است و نباید بدون طراحی احراز هویت و سیاست‌های دسترسی امن در محیط عمومی استفاده شود.
